# Site Features

Snapshot of what the live site renders today, as the starting point for the 2025 refactor. Every feature below must survive the refactor unless explicitly scoped out.

## Pages

All pages inherit from `src/templates/base.njk`. Data comes from the global `allNames`, `classifications`, and `siteConfig` values in `.eleventy.js`.

### Homepage — `/`
- Template: `src/index.njk`
- Hero block, stats (40,000+ names, 120 years), search input.
- Six classification preview cards (Vintage Revival, Steady Classics, Lost Generation, Recent Entrants, Pendulum, Declining Favorites) linking to the relevant classification detail pages.
- Four featured name journeys (Oliver, Muhammad, Ivy, Sharon) rendered from the `allNames` dataset.
- About section.

### All-names landing — `/names/`
- Generated as an auto-index of `/names/boy/…` and `/names/girl/…`. No dedicated template in `src/`; Eleventy creates the directory listing as a side-effect of the paginated name pages.

### Individual name page — `/names/{gender}/{uniqueSlug}/`
- Template: `src/name-pages.njk` (paginated over `allNames`, size 1).
- Permalink: `/names/{{ nameData.gender | lower }}/{{ nameData.uniqueSlug }}/`.
- Header: name, gender, current rank, 2024 count.
- Three classification badges (five_year, recent, historic) — each links to its classification detail page.
- Four narrative bullet points (`bulletPoint1`–`bulletPoint4`).
- Historic rankings table across 13 decades (1904–2024) from `rankHistoric`.
- Related-names section rendered from `relatedNamesWithRank` (enriched at build time with rank, gender, and `uniqueSlug`).

### Classification overview — `/patterns/`
- Template: `src/classifications.njk`.
- Three grouped sections (historic, recent, five_year) with a card per classification showing description, example names, and count badge.

### Classification detail — `/classifications/{type}/{slug}/`
- Template: `src/classification-pages.njk` (paginated over `classifications`, size 1).
- Types: `five_year`, `recent`, `historic`.
- Shows classification name, description, period, and all matching names split into two gender columns with rank badges.

### Top 100 by year — `/top-100/`
- Template: `src/top-100.njk`.
- Gender tabs (boys/girls), year selector from 1996–2024, client-side table render pulled from the name JSON.

## Search

- Client script: `src/scripts/search.js` (Fuse.js fuzzy match).
- Index: `_site/search-index.json` — emitted by the `eleventy.after` hook in `.eleventy.js:246`. One entry per name with `{name, slug, gender, rank}`.

## URL structure

| Path | Source template |
|---|---|
| `/` | `src/index.njk` |
| `/names/boy/<slug>/` | `src/name-pages.njk` |
| `/names/girl/<slug>/` | `src/name-pages.njk` |
| `/patterns/` | `src/classifications.njk` |
| `/classifications/<type>/<slug>/` | `src/classification-pages.njk` |
| `/top-100/` | `src/top-100.njk` |
| `/search-index.json` | generated in `.eleventy.js:246` |
| `/styles/main.css` | built by PostCSS |
| `/scripts/search.js` | passthrough from `src/scripts/` |

`uniqueSlug` disambiguates names that appear in both boys and girls lists (and duplicates within a gender) — generated by `scripts/generate-unique-slugs.js` and consumed directly by the permalink.

## Styling and assets

- Tailwind v4 via `@tailwindcss/postcss`. Entry: `src/styles/main.css`. Output: `_site/styles/main.css`.
- `src/scripts/` is passthrough-copied to `_site/scripts/`.
- `src/assets/` is passthrough-copied if present.

## Build modes

`.eleventy.js:7` picks between two datasets:

- **Production** — `data/boys.json` + `data/girls.json`, full dataset.
- **Development** — `data/boys-dev.json` + `data/girls-dev.json`, top 500 per gender, generated by `scripts/create-dev-data.js`.

Selection logic:
1. `USE_DEV_DATA=true|false` environment variable (explicit override).
2. Otherwise: `main` branch → production, any other branch → dev.

npm scripts (`package.json`):
- `npm run build` — eleventy + PostCSS, honours the mode above.
- `npm run build:dev` / `npm run build:prod` — force-set `USE_DEV_DATA`.
- `npm run dev` — regenerates dev JSON, starts Eleventy on port 1872 with CSS watcher.
- `npm run dev:data` — only refresh `boys-dev.json` / `girls-dev.json`.

Production Node heap is raised to 8GB via `NODE_OPTIONS=--max-old-space-size=8192` for the full dataset build.
